    Quick help

    • Open model… loads your Tripo3D/Mixamo character (FBX or GLB). Drop files on the viewport too.
    • Import files / folder adds animations to the library. Packs are grouped by folder name.
    • Click a coloured joint to pose it (green = left, orange = right). E rotate, W move hips, Esc deselect.
    • New clip, pose, K to key, move the playhead, pose, K again. Space plays.
    • Write what you want in Direction notes, then export a Reference pack or let Claude Code / Codex read it live through the AI link (see README).
